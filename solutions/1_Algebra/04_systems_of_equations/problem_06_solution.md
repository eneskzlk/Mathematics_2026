# Exercise 6 — Parameter Analysis

## Question

Analyze, depending on the parameter $a$, the system

$$
\begin{cases}
x+y=2, \\
ax+ay=4.
\end{cases}
$$

Among the three possibilities — exactly one solution, infinitely many solutions, no solution — determine which actually occur and for which values of $a$. If one type cannot occur, explain why.

## Solution

Subtract $a$ times equation 1 from equation 2. The result is

$$
0=4-2a.
$$

If $a=2$, equation 2 is exactly twice equation 1 and all $(x,y)=(t,2-t)$ are solutions: **infinitely many**.

If $a\ne2$, the transformed equation is a contradiction: **no solution**.

A **unique solution never occurs**, because the coefficient rows $(1,1)$ and $(a,a)$ are proportional for every $a$.
